## Відкрити

Із кореня репозиторію:

```sh
node mockups/anti-slop-prototype/server.mjs
```

- [A / Авторська майстерня](http://127.0.0.1:8768/?variant=A&page=home&lang=uk)
- [B / Каталог інструментів](http://127.0.0.1:8768/?variant=B&page=home&lang=uk)
- [C / Спочатку демонстрація](http://127.0.0.1:8768/?variant=C&page=home&lang=uk)

Панель унизу перемикає A/B/C та сторінки. Кнопка **«Що змінили?»** пояснює конкретну пропозицію для відкритої сторінки. Стрілки клавіатури ← → перемикають варіант, якщо фокус поза полем, кнопкою, відео чи діалогом. URL можна копіювати; навігація назад/уперед підтримується. За зайнятого порту використай `PROTOTYPE_PORT=8769 node mockups/anti-slop-prototype/server.mjs`.

## Покриття

Головна; Папуга; AppCat; Дідуня; SideBarny; WayForPay MCP; ukraine.com.ua MCP; підбір інструмента; журнал оновлень; окреме оновлення; про Романа; дані й умови; 404.

[План змін для кожної сторінки](PAGE-PLAN.md) містить початкові проблеми, запропоновану подачу й межі можливостей. Це ширша карта наступної роботи: наприклад, окремі відео другорядних сценаріїв та фільтр майбутнього журналу ще не реалізовані. У прототипі журнал має один наявний запис, тому фільтр не потрібен.

Працюють пошук і фільтри, інтерактивна схема SideBarny, діалоги MCP та копіювання конфігурації. Посилання на репозиторії й релізи зовнішні; сама сторінка не встановлює програми та не викликає API.

Кожен ролик: 12 секунд, 1280 × 800, H.264, 30 fps, без звуку. Є постер, українські субтитри та стандартні елементи керування; автоматичного запуску немає. Сумарний розмір MP4 - приблизно 395 КБ.

**Це сценарні відтворення з умовними даними, не записи встановлених апок.** Позначка є у відео та поруч із плеєром. Візуальна форма інтерфейсу спрощена; тривалість сцени не є виміром швидкодії. Для публічної версії потрібні записи підтверджених сценаріїв у релізних застосунках. Джерело для редагування відео: [video-source/BRIEF.md](video-source/BRIEF.md), HyperFrames 0.8.91.

## Джерела й межі

Факти взято з каталогу від 28.09.2026 (локальний дослідницький каталог, не включений у PR), релізного коду та чинних шаблонів сайту. Релізні версії явно датовані; поточний production/runtime цим прототипом не перевіряється. MCP-приклади використовують умовні credentials і вимикають write tools; запуск MCP тут не тестувався.

Справжні іконки скопійовані з локальних ресурсів Papuga, AppCat та Diduny. `assets/before-home.png` - попередній знімок сайту з дослідницького аудиту. Портретів, цитат клієнтів і нових релізних історій не вигадано. Правова сторінка демонструє структуру, а не встановлює нову політику.

Прототип ізольований у цьому каталозі. Astro-сторінки, маршрути, canonical/hreflang, індекси, фіди та production-стилі не змінені. Сервер слухає лише `127.0.0.1`; немає аналітики, форм збору даних або збереження пошукових запитів. Прототип не розгорнутий публічно.

## Перевірка

- Два окремі проходи: перевірка продуктових тверджень за джерелами та перевірка взаємодії/макетів у браузері. Виправлено вимоги runtime MCP, обов’язкові дати пошуку WayForPay та пояснення передачі DNS token.
- 78 станів на ширині 390 px і 78 на настільному екрані: один H1, коректна сторінка/мова, без горизонтального переповнення. Українські мобільні сторінки також перевірені на наявність цілей внутрішніх якорів.
- Перевірено пошук DNS, порожній результат, скидання, фільтр MCP, передачу фрагмента SideBarny, копіювання прикладу MCP, відкриття/закриття діалогів, перемикання стрілкою, Back і збереження вибору після reload. Невідому назву сторінки перевірено до/після виправлення: вона відкриває 404, а не успадковану властивість об’єкта.
- `node --check` для `app.js`, `data.js` та `server.mjs`.
- HyperFrames: lint/runtime/layout/motion без помилок і попереджень; 52/52 перевірок контрасту відеосцен пройдено. Готові MP4 перевірені через ffprobe, ключові кадри переглянуті. У браузері всі три плеєри мають тривалість 12 секунд і відтворюються без media error; console error/warning у фінальній перевірці немає.
- Це перевірка локального прототипу, не повний аудит доступності й не перевірка встановлення продуктів.

## Спрощення від 30.09.2026

Один головний приклад Папуги, короткий вступ і каталог під заголовком «Для Mac». Прибрані перемикачі апок на головній, повторний блок автора, версії у каталозі та повторне завантаження внизу продуктів. Кожна апка має власну демонстрацію на своїй сторінці. Внутрішні посилання мають стрілку →, зовнішні - ↗.

Сторінки продуктів: опис і демонстрація; можливості; перед встановленням (із відповіддю на часте питання); дані. Вимоги, обмеження та пояснення приватності збережені.

Перевірка: `PROTOTYPE_URL=http://127.0.0.1:8768 node mockups/anti-slop-prototype/check.mjs` після запуску сервера. Потрібні `npm ci` та `npx playwright install chromium`.

Для Git-перевірок: `mise install`, `mise exec -- lefthook install`. Версії scanner і hook runner зафіксовані в `mise.toml`. Pre-commit перевіряє staged files, pre-push і CI - історію PR від `origin/main`.
